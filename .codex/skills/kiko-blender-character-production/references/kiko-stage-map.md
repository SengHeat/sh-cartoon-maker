# KIKO 14-Stage Map

| Stage | Description | Gate |
|---|---|---|
| 1 | Project Audit | Verify sources and known-good files |
| 2 | 5s Run Locomotion Test | Believable run, no unacceptable foot sliding |
| 3 | V2 Expressive Rig | Face/viseme/acting controls |
| 4 | 8s Acting Test | Body + face + ears + tail |
| 5 | Final Visual KIKO Asset | Final visual identity passes |
| 6 | Fur + Materials | Remove rubber/plastic appearance |
| 7 | Rig Fit to Final Visual | Fit existing rig to approved mesh |
| 8 | Deformation QA | Extreme poses do not collapse/pinch |
| 9 | Re-run Locomotion + Acting | Verify on final KIKO |
| 10 | Khmer Lip-sync Foundation | Viseme pipeline |
| 11 | Final Cinematic Look | Lighting/atmosphere/composition |
| 12 | 30s Production Test | Full-quality short sequence |
| 13 | 60s Episode | Story-driven episode |
| 14 | YouTube Production Pipeline | Repeatable documented workflow |

Never skip an unresolved visual/deformation gate just to reach animation.
