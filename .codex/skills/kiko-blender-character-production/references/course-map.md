# Course Map

This map follows the supplied character-creation course topics.

| Topic | Production purpose |
|---|---|
| 01. Topology | Deformation-friendly mesh structure |
| 02. 3D Modeling Head | Face identity, cheeks, muzzle, eyes |
| 03. Modeling Torso | Chest, waist, pelvis |
| 04. Modeling Limbs | Arms, legs, hands, feet |
| 05. Creating Clothes — T-shirt and Shorts | Basic clothing construction |
| 06. Modeling Clothes — Jacket and Shoes | Layered clothing |
| 07. Modeling Props and Details | Bags, accessories, details |
| 08. Cleanup and UVs | Mesh cleanup and UV preparation |
| 09. Texturing and Shading Body | Body/fur surface work |
| 10. Texturing and Shading Clothes and Props | Cloth, leather, accessories |
| 11. Rendering Still Character | Beauty/review render |
| 12. Rigging Introduction | Armature concepts |
| 13. Rigify — Creating Armature | Rig creation when no verified rig exists |
| 14. Rigify — Generating, Auto Weights | Initial rig generation/weights |
| 15. Rig Interface / Customization | Controls and animator usability |
| 16. Skin Weight Painting | Correct deformation |
| 17. Rigging Props — Bag and Cap | Parent/weight accessories |
| 18. Pose Library and Character Linking | Reusable acting system |
| 19. Walk Cycle | Locomotion fundamentals |
| 20. Secondary Animation / Cloth / Props | Ears, tail, clothing, props |
| 21. Final Render / Compositing | Production render/composite |

For KIKO, do not use the rigging chapters as justification to replace the existing verified V2 rig automatically.
